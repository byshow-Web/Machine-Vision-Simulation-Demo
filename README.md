本项目主要为机器视觉在自动化设备中的仿真运用 通过传统机器视觉 视觉算法（cv yolo） 视觉坐标平台2D 3D坐姿对齐等模块的应用完成产业化工程  
   本项目核心点在于：1.图像预处理：针对工业视觉测量中原始图像存在噪声、光照不均以及目标与背景对比度不足等问题，首先对采集到的图像进行预处理。通过灰度化、滤波去噪、增强对比度以及二值化等操作，
有效抑制图像中的干扰信息，突出盖板目标区域，使目标与背景形成较为明显的灰度差异。在此基础上得到质量较高的二值图像，为后续 Blob 分析和特征提取提供稳定可靠的图像数据。
   2.Blob分析：在完成图像预处理后，对二值图像进行 Blob 连通区域分析，将图像中的目标区域进行分离和提取。通过对不同连通区域的面积、中心位置、外接矩形以及长宽等几何特征进行分析，可以有效排除噪声区域和无关目标，
最终确定盖板对应的有效 Blob。通过 Blob 的中心坐标可以获得目标在图像坐标系中的位置，同时结合目标轮廓及几何尺寸信息，为后续的尺寸测量和位置计算提供基础数据。
   3.位置修正：由于实际测量过程中盖板可能存在位置偏移、装夹误差以及每次采集位置不完全一致等情况，因此在 Blob 检测得到目标坐标后，需要进行位置修正。通过建立参考位置，将当前检测到的目标中心坐标与基准坐标进行对比，
计算目标在 X、Y 方向上的偏移量，并根据偏移结果对测量区域或目标坐标进行补偿。经过位置修正后，可以降低工件位置变化对测量结果造成的影响，提高视觉测量系统的稳定性和重复定位精度，为后续标定转换及实际尺寸计算提供更加
准确的坐标数据

本项目围绕机器视觉系统的四个核心环节展开，通过仿真环境模拟真实产线的视觉检测流程：
| 模块      | 作用                           | 核心技术   |
| ------- | ---------------------------- | ------ |
| 检测单元构建  | 搭建视觉检测工位，配置相机、光源与工件，构建图像采集场景 | 仿真场景搭建 |
| 运动单元构建  | 配置运动机构与工件流转，模拟产线输送与定位        | 仿真机构控制 |
| 视觉算法构建  | 调用传统图像处理算法完成定位、测量、识别等检测任务    | OpenCV |
| AI 模型构建 | 集成深度学习模型，实现目标检测与智能分类         | YOLO   |
